    Lecture 2 · 复杂性分析¶

    来源：算法设计与分析 / 复杂性分析.md

    本讲课件 · 上一讲：引论 · 下一讲：级数求和与递推关系

    问题、实例与输入规模¶

    问题规定参数、取值范围和解应该满足的要求。实例是把所有参数赋成具体值。例如，查找问题接收数组 \(A\) 和目标 \(x\)，\(A=[1,3,7,8],x=7\) 就是一个实例。一个正确的确定性算法接收任意合法实例，经过有限步得到满足要求的输出。

    分析运行时间时，先选定输入规模以及要计算的基本操作。输入规模反映描述实例所需的信息量，基本操作是该分析所采用的计量单位。

    问题 规模 常用基本操作
    排序、查找 数组长度 \(n\) 比较元素，或移动元素
    两整数相乘 两数二进制位数 \(m,n\) 竖式算法的逐位操作
    矩阵乘法 矩阵维度 \(m\times n\)、\(n\times p\) 标量乘法，朴素算法恰好进行 \(mnp\) 次
    图遍历 顶点数 \(n\)、边数 \(m\) 访问顶点，枚举邻接边

    数组元素可以用机器字表示时，一次数组访问通常按常数时间计。若每项是很长的整数，分析就要看是在数整数运算次数，还是在数位操作次数。例如，正整数 \(N\) 的二进制位数是 \(\lfloor\log_2N\rfloor+1\)，整数 \(1024\) 有 \(11\) 位。

    最好、最坏和平均情况¶

    记 \(X_n\) 为所有规模为 \(n\) 的实例，\(t(x)\) 为处理实例 \(x\) 的基本操作数。若随机实例 \(X\) 服从分布 \(p_n\)，则

    类型 数学表达 回答的问题
    最好情况 \(B(n)=\min_{x\in X_n}t(x)\) 规模相同时，最容易的实例需要多少步
    最坏情况 \(W(n)=\max_{x\in X_n}t(x)\) 规模相同时，最难的实例需要多少步
    平均情况 \(A(n)=\operatorname{E}[t(X)]=\sum_{x\in X_n}p_n(x)t(x)\) 按给定分布抽取一个实例时，期望需要多少步

    平均复杂度要说明输入分布。例如，对数组头部元素的查询特别多时，顺序查找的平均比较次数会下降。随机算法还可以固定输入，对算法内部的随机选择取期望。

    这个区别在密码学里尤其明显。密码方案运行时，会按规定的分布生成问题实例。如果困难实例只占极少一部分，而且生成过程很少抽到它们，那么一个最坏情况困难的结论就不足以说明生成出的实例有多难解。需要分析的是具体生成分布及其对应的计算任务。

    顺序查找的期望¶

    每次拿目标 \(x\) 和一个数组元素比较，返回第一次匹配的位置。下面用 Python 的零基下标，数学计数中仍按第 \(1\) 到第 \(n\) 个位置编号。

    def search(items, target):
    for index, item in enumerate(items):
        if item == target:
            return index
    return -1

    命中第 \(i\) 个位置，比较 \(i\) 次。目标缺失或直到最后一个位置才命中，比较 \(n\) 次。假设命中概率为 \(p\)，且给定命中后，首次命中位置在 \(n\) 个位置上均匀分布，则每个位置首次命中的无条件概率是 \(p/n\)。

    \[ \begin{aligned} A(n) &=\sum_{i=1}^{n} i\frac pn+n(1-p)\\ &=\frac{p(n+1)}2+n(1-p). \end{aligned} \]

    例如 \(n=5,p=1/2\) 时，命中部分平均比较 \(3\) 次，未命中部分固定比较 \(5\) 次，加权得到 \(A(5)=4\)。在这组假设下，\(p\) 即使取 \(1\)，期望也有 \((n+1)/2\) 次，仍是线性增长。

    用伪代码找到要证明的性质¶

    伪代码把实现写成可以逐行执行的过程，保留赋值、循环、分支和递归。写清下标从哪里开始、循环何时停止、返回什么，后续就可以逐行计数，或者为循环写不变量。

    欧几里得算法¶

    对 \(a\ge b>0\)，反复令 \((a,b)\leftarrow(b,a\bmod b)\)，当 \(b=0\) 时返回 \(a\)。每一步保持

    \[ \gcd(a,b)=\gcd(b,a\bmod b). \]

    因为 \(a=qb+r\)，\(a,b\) 的公因数也整除 \(r=a-qb\)，\(b,r\) 的公因数同样整除 \(a=qb+r\)。非零余数每次严格减小，最终必到 \(0\)。

    取余前 \((a,b)\) 余数 \(r\) 取余后 \((a,b)\)
    \((36,15)\) \(6\) \((15,6)\)
    \((15,6)\) \(3\) \((6,3)\)
    \((6,3)\) \(0\) \((3,0)\)

    循环中的两个变量在算什么？¶

    给定多项式系数 \(P[0],\ldots,P[n]\)，从低次到高次累加。power 从 \(1\) 开始，每轮乘一次 \(x\)，更新后的值是 \(x^i\)。到第 \(i\) 轮结束时，value 是 \(\sum_{j=0}^i P[j]x^j\)。

    power ← 1
value ← P[0]
for i ← 1 to n
    power ← power × x
    value ← value + P[i] × power
return value

    例如 \(P=[2,3,4],x=2\)。初始值为 \(2\)，两轮分别加 \(3\cdot2\)、\(4\cdot4\)，得 \(24\)。这个版本做 \(2n\) 次标量乘法和 \(n\) 次加法。若使用 Horner 法，从最高次项往回做 \(y\leftarrow yx+P[i]\)，乘法可减为 \(n\) 次，渐近量级仍为 \(\Theta(n)\)。

    插入排序的外层不变量是“前缀已经有序”，归并排序合并前需要两个子区间分别有序，相应步骤见引论。

    五种渐近记号¶

    在有序数组 \([2,4,6,8,10,12,14]\) 里找 \(15\)。顺序查找要把 \(7\) 项都看一遍，二分查找依次看 \(8,12,14\)，比较 \(3\) 次就知道目标不在数组里。如果数组有 \(15\) 项，最坏分别要比较 \(15\) 次和 \(4\) 次。顺序查找的最坏次数随项数一起增加，是 \(O(n)\)。二分每比较一次，就把剩余范围缩到原来的一半以内，项数翻倍时最坏只多一次比较，是 \(O(\log n)\)。

    下面用 \(f(n)\) 表示要分析的次数，用 \(g(n)\) 作参照。当 \(n\) 充分大时，假设 \(f(n)\ge0\)、\(g(n)>0\)，令 \(r_n=f(n)/g(n)\)。下表的不等式要对每个 \(n\ge n_0\) 成立，起点 \(n_0\) 可以随所选的常数而变。

    记号 常数与阈值 等价的极限条件
    \(f=O(g)\) 存在 \(c>0,n_0\)，使 \(f(n)\le cg(n)\) \(\limsup r_n<\infty\)
    \(f=\Omega(g)\) 存在 \(c>0,n_0\)，使 \(f(n)\ge cg(n)\) \(\liminf r_n>0\)
    \(f=\Theta(g)\) 存在 \(c_1,c_2>0,n_0\)，使 \(c_1g(n)\le f(n)\le c_2g(n)\) \(0<\liminf r_n\le\limsup r_n<\infty\)
    \(f=o(g)\) 对任意 \(c>0\)，存在 \(n_0\)，使 \(f(n)<cg(n)\) \(\lim r_n=0\)
    \(f=\omega(g)\) 对任意 \(c>0\)，存在 \(n_0\)，使 \(f(n)>cg(n)\) \(\lim r_n=+\infty\)

    例如对 \(n\ge1\)，有 \(3n+2\le5n\)。从这里就能写出 \(3n+2=O(n)\)，常数取 \(5\)，起点取 \(1\)。\(O\) 说明所写的是上界。若要说分析的是哪种输入情况，可以写清楚 \(W(n)\) 或 \(A(n)\)，例如顺序查找最坏比较 \(W(n)=n\) 次，因此 \(W(n)=\Theta(n)\)。

    同一个函数可以有多个上界¶

    设 \(f(n)=32n^2+17n+1\)。当 \(n\ge1\)，有

    \[ 32n^2\le f(n)\le(32+17+1)n^2=50n^2. \]

    于是 \(f(n)=\Theta(n^2)\)。它也是 \(O(n^3)\)，因为 \(n^2\le n^3\)。比值 \(f(n)/n^3\to0\)，还可以说它是 \(o(n^3)\)。

    若 \(\lim r_n=c\) 且 \(0<c<\infty\)，取误差 \(c/2\)，最终有 \(c/2<r_n<3c/2\)，于是 \(f=\Theta(g)\)。即使普通极限不存在也可能有紧界，比如 \(f(n)=(2+(-1)^n)n\) 与 \(g(n)=n\) 的比值在 \(1\) 和 \(3\) 间交替。从 \(1\le f(n)/g(n)\le3\) 直接得到 \(f=\Theta(g)\)。

    两段程序如何合并估计？¶

    • 顺序执行时相加。若 \(f_i=O(g_i)\)，则 \(f_1+f_2=O(\max\{g_1,g_2\})\)，因为 \(g_1+g_2\le2\max\{g_1,g_2\}\)
    • 等成本重复时相乘。若共做 \(O(g_1)\) 次，每次最多 \(O(g_2)\)，则总量为 \(O(g_1g_2)\)。每次成本会变时，先写出求和，比如第 \(i\) 轮做 \(i\) 次操作，总量为 \(\sum_{i=1}^n i=n(n+1)/2\)
    • 界可以传递。若 \(f=O(g)\) 且 \(g=O(h)\)，选取两个阈值中较大的一个就有 \(f(n)\le c_1g(n)\le c_1c_2h(n)\)

    多个参数也可以一起写。例如邻接表上的广度优先搜索用 \(O(n+m)\) 时间，每个顶点最多入队一次，每条邻接记录最多检查一次。若要证明 \(f(m,n)=O(g(m,n))\)，常数需要独立于 \(m,n\)。在没有额外关系时，像 \(32mn^2+17mn+32n^3\) 这样的式子可以化到 \(\Theta(mn^2+n^3)\)，两个参数项都保留。

    试除法为什么是指数时间？¶

    若合数 \(N=ab\) 且 \(1<a\le b\)，则 \(a\le\sqrt N\)。所以试除法检查 \(2,\ldots,\lfloor\sqrt N\rfloor\)，找到因数时提前退出。

    对固定的整数 \(N\)，至多做 \(O(\sqrt N)\) 次试除。有些整数立即被小因子整除，例如奇数 \(N=9(2k+1)\) 只需要试到 \(3\)。素数则会走完整个区间。

    令 \(\lambda=\lfloor\log_2N\rfloor+1\)，于是 \(2^{\lambda-1}\le N<2^\lambda\)。对同样长的 \(\lambda\) 位输入，最大试除次数是 \(\Theta(2^{\lambda/2})\)。上界来自 \(\sqrt N<2^{\lambda/2}\)，下界可用每个充分大的位长都有素数这一事实，由 Bertrand 公设取 \(2^{\lambda-1}\) 和 \(2^\lambda\) 之间的素数。这里计的是取模次数。若把大整数取模本身的位操作也计入，时间还要加入每次取模的代价。

    常见增长率¶

    取常量 \(\alpha,d,c,k\)，其中 \(0<\alpha<1<d\)、\(c>1\)、\(k>1\)。每一项相对于下一项都是小 \(o\)。

    \[ 1,\quad \log\log n,\quad \log n,\quad (\log n)^k,\quad n^\alpha,\quad n,\quad n\log n,\quad n^d,\quad c^n,\quad n!,\quad n^n \]
    • 对数换底。\(\log_a n=\log_b n/\log_b a\)，当底数 \(a,b\) 是大于 \(1\) 的常数时，只相差一个常数因子
    • 正次幂快于对数。对任意 \(\alpha>0\)，用洛必达法则有 \(\lim_{x\to\infty}(\ln x)/x^\alpha=\lim_{x\to\infty}1/(\alpha x^\alpha)=0\)
    • 指数快于固定次幂。\(\ln(n^d/c^n)=d\ln n-n\ln c\to-\infty\)，所以 \(n^d/c^n\to0\)

    阶乘如何估计？¶

    Stirling 公式给出

    \[ n!\sim\sqrt{2\pi n}\left(\frac ne\right)^n,\qquad \ln(n!)=n\ln n-n+O(\ln n). \]

    只想证明 \(\ln(n!)=\Theta(n\ln n)\) 时，可以按最后一半因子估计。上界是 \(\ln(n!)\le n\ln n\)，下界是 \(\ln(n!)\ge\lfloor n/2\rfloor\ln(n/2)\)，量级已经确定。

    回到投资回报问题。例如取 \(m=n-1=k\)，枚举的方案数为中央二项式系数，

    \[ \binom{2k}{k}\sim\frac{4^k}{\sqrt{\pi k}}. \]

    这说明投入枚数和项目数一起增加时，搜索空间可以呈指数增长。固定项目数 \(n\) 时，方案数 \(\binom{m+n-1}{n-1}\) 则是关于 \(m\) 的 \(n-1\) 次多项式。

    上取整和下取整¶

    \[ x-1<\lfloor x\rfloor\le x\le\lceil x\rceil<x+1. \]

    若 \(n\) 是整数，则 \(\lfloor n/2\rfloor+\lceil n/2\rceil=n\)。递归把长度为奇数的数组分成两半时，就可以分别写成这两个大小。若二分查找先比较中间元素再把它剔除，剩下两侧中的较大一侧至多有 \(\lfloor n/2\rfloor\) 个元素。递归到底时仍要写清何时停止。

    重复做整数等分时，有

    \[ \left\lfloor\frac{\lfloor n/a\rfloor}{b}\right\rfloor =\left\lfloor\frac{n}{ab}\right\rfloor,\qquad \left\lceil\frac{\lceil n/a\rceil}{b}\right\rceil =\left\lceil\frac{n}{ab}\right\rceil \quad(a,b\in\mathbb Z_{>0}). \]

    以下取整为例，左侧给出满足 \(qb\le\lfloor n/a\rfloor\) 的最大整数 \(q\)。因为 \(qb\) 本来就是整数，该条件等价于 \(qb\le n/a\)，所以最大值就是右侧。

    课件也用密码学中的舍入来说明离散化。以 \(q<p\) 为例，\(\lfloor qx/p\rfloor\) 能把 \(x\in\{0,\ldots,p-1\}\) 的取值压缩到 \(q\) 个区间。同一区间可能包含多个原值，对应部分信息的丢失。这个例子只描述舍入操作，具体安全性还取决于方案和模型。

    从式子读出运行时间¶

    量级 例子 怎么数
    \(\Theta(1)\) 读取数组元素、访问已知的整数最低有效位 用固定次数访问
    \(\Theta(\log n)\) 二分查找的最坏时间 每次比较后至多剩一半，经过约 \(\log_2 n\) 轮只剩常数个元素
    \(\Theta(n)\) 合并两份各有 \(n\) 项的有序表 每比较一次消耗一个表头，初始有 \(2n\) 项，比较次数介于 \(n\) 和 \(2n-1\)
    \(\Theta(n\log n)\) 普通归并排序 约 \(\log_2 n\) 层，每层合并总代价为 \(\Theta(n)\)
    \(\Theta(n^2)\) 枚举平面中的所有点对来找最近点对 一共 \(\binom n2\) 对，假定每对距离用常数个算术操作求出
    \(\Theta(n^3)\) 朴素方阵乘法 \(n^2\) 个输出元素，每项累加 \(n\) 个乘积
    \(O(n^k)\)，固定 \(k\) 判断是否存在大小为 \(k\) 的独立集 枚举 \(\binom nk\) 个集合，用邻接矩阵检查每个集合内的 \(O(k^2)\) 对顶点
    \(O(n^2 2^n)\) 枚举顶点子集求最大独立集 枚举 \(2^n\) 个集合，每个集合至多查 \(O(n^2)\) 对顶点

    固定 \(k=17\) 时，\(n^{17}\) 仍是多项式，但对一般输入可能很慢。若 \(k\) 本身也随输入增长，就要把它保留在复杂度里，例如 \(k=n/2\) 时枚举 \(\binom nk\) 个集合需要指数时间。

    同一个量级下，常数也影响实际时间¶

    对同一个 \(n\) 次多项式求值，前面的逐次累积幂做 \(2n\) 次乘法，Horner 法做 \(n\) 次。两者都是 \(\Theta(n)\)，但如果乘法是主要代价，少做这 \(n\) 次就有直接收益。比较具体实现时，除了渐近量级，还可以数关键操作或在实际数据规模上测时间。

    自测¶

    1. 若 \(f(n)\) 在偶数处为 \(n^2\)，奇数处为 \(n\)，能用哪些渐近界描述它？
    2. 用 \(n=8,p=1/4\) 代入顺序查找的式子，比较期望次数与最坏次数
    3. 两个同长度的整数，一个能被 \(3\) 整除，一个是素数，试除次数为什么可能相差很多？
    4. 把正整数的二进制输入长度从 \(20\) 位增至 \(40\) 位，试除次数的最坏量级会乘上多少？
